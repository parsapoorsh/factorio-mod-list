# factorio-mod-list

Local Factorio mod sources used by the headless server, tracked as git submodules.

## Setup

```bash
git clone --recurse-submodules git@github.com:parsapoorsh/factorio-mod-list.git
# or after a plain clone:
git submodule update --init --recursive
```
